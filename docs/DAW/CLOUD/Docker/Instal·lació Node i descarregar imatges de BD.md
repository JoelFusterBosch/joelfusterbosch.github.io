## Instal·lació de Node.js
En Linux anem a la terminal i posarem el següent per a instal·lar Node.js:

```bash
sudo apt install nodejs
```

    <img src="../imatges/Instal·lació Node i descarregar imatges de BD/Instal·lació de Node.png" alt="Comand per a la instal·lació de Node" width="300"/>
</p>
<p align="center"><em>Comand per a la instal·lació de Node</em></p> 

Per a vore si s’ha instal·lat correctament podem executar el següent per a vore la versió de `Node.js`:

```bash
nodejs --version
```

## Instal·lació de Express

Ara per a instal·lar Express necessitem instal·lar-lo a través dels paquets de Node, més específicament amb `npm`:
```bash
npm install express
```

<p align= "center">
    <img src="../imatges/Instal·lació Node i descarregar imatges de BD/Instal·lació de express.png" alt="Instal·lació de express" width="300"/>
</p>
<p align="center"><em>Instal·lació de express</em></p> 

I per a vore si s’ha instal·lat correctament i vore la versió de Express podem veure-ho des del següent comand:

```bash
npm express --version
```
