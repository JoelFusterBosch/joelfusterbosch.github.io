Per a començar en Vue, es recomanable crear una nova carpeta:
En Linux:
```bash
mkdir vue inici
```
I dins de ella anem a executar el següent comand:
```bash
npm create vue@latest
```
Apareixera uns menus per a instal·lar altres llibreries, però de moment no anem a instal·lar res:

Quan s'instal·le entra a la carpeta del projecte i fes `npm install`
```bash
npm install
```
I si vols vore el resultat en la web fes:
```bash
npm run dev
```
